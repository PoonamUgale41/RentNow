# RentNow

A modern rental property website built with React and Vite.

## Features
- Property listing and search
- Featured property cards
- Property details page
- Login and registration pages
- About and Contact pages
- Responsive UI

## Tech Stack
- React
- Vite
- CSS
- React Router DOM

## Installation

```bash
npm install
```

## Run the project

```bash
npm run dev
```

## Build for production

```bash
npm run build
```

## Project Structure

```bash
src/
  Components/
  Views/
  data/
  assets/
  App.jsx
  main.jsx
```
